### Week 2: Data Visualization and Insight Communication

**Focus:** Analyzing Reliance Industries stock data using R.

The analysis uses historical stock market data for Reliance Industries from **6 May 2025 to 5 May 2026**, containing 248 observations.

**Key activities:**

* Exploring daily stock prices and returns
* Visualizing daily closing-price movements
* Examining the distribution of daily returns
* Investigating the relationship between trading volume and closing price
* Comparing monthly average closing prices
* Identifying potential outliers in daily returns
* Interpreting results and communicating business-relevant observations

**Visualizations created:**

* Daily closing-price line chart
* Daily returns line chart
* Daily returns histogram
* Trading volume versus closing-price scatter plot
* Monthly average closing-price line chart
* Daily returns boxplot

The analysis combines R code, visual outputs, descriptive statistics, and written interpretations to communicate the findings clearly.

## 📈 Key Analytical Findings

* The highest observed closing price was approximately **₹1,592 on 2 January 2026**.
* The lowest observed closing price was approximately **₹1,305 on 7 April 2026**.
* The average daily return was approximately **0.0174%**.
* The standard deviation of daily returns was approximately **1.30%**.
* The correlation between trading volume and closing price was approximately **−0.359**, indicating a moderate negative linear association in this dataset.

These findings describe the selected dataset and observation period. Correlation does not establish causation, and the results should not be treated as investment advice.
